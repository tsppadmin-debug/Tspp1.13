Agrandir is a paid typeface from Pangram Pangram, so it is not included in this repo.
After buying or receiving the licence, add these two files to this folder:

  Agrandir-Regular.woff2
  Agrandir-Bold.woff2

Convert the .otf or .ttf files you receive to .woff2 first (for example at https://cloudconvert.com/otf-to-woff2).
Commit and push. The site picks them up on its own, no code change needed.
Until then, headings use Outfit as a stand in.
